# Осколок

Исходники находятся в этом каталоге. Production: https://oskolok.lol/, VPS 185.166.153.240.
Отвечай владельцу кратко по-русски. Исправляй подтверждённые проблемы, сохраняя работающие функции и чужие незакоммиченные изменения.

## Работа

- Меняй исходники локально; `npm run dev:web` запускает сайт и API для разработки.
- Для браузерных проверок используй отдельную QA-базу и вымышленные аккаунты. Не изменяй данные настоящих слушателей при проверках.
- Перед публикацией нужны `npm run build` и `npm test`. Команда `npm run deploy` сама запускает эти проверки, создаёт отдельный выпуск на VPS, проверяет его на пустой QA-базе, делает backup и переключает сайт. При неудачном запуске возвращает предыдущий выпуск.
- Не заменяй создание ссылки на общий кэш простой командой `ln -s`: QA создаёт `server/data`, и ссылка окажется внутри папки. Сохраняй `scripts/deploy/link-data.mjs`, проверку записи `check-cache.mjs` под ограничениями службы и регрессионный тест `deploymentCache.test.ts`.
- `npm run deploy` публикует изменения для пользователей; запускай, когда владелец просит выложить обновление.
- Не редактируй `/opt/oskolok/current` на месте. Не заменяй production SQLite, `private` или `user-content` файлами с компьютера.
- Не копируй `.env`, базы, ключи, сессии и пароли в репозиторий, логи или дистрибутивы. SSH уже настроен локальным ключом; секреты VPS остаются в `/etc/oskolok/oskolok.env`.
- Изменения основной Prisma-схемы требуют отдельной совместимой миграции и проверки восстановления; публикация автоматически не применяет `db push` к production.

## Обновления приложений

EXE, DMG и APK из `release/distribution` открывают общий сайт. Изменения сайта приходят без повторной установки. Открытый клиент проверяет `version.json` каждые три минуты и при возврате на экран. Обновление применяется без проигрывания музыки, редактирования формы или открытого диалога; доступна кнопка «Обновить».
Изменения самой нативной оболочки требуют новой сборки/установки; автоматического обновления исполняемых файлов сейчас нет.

Подробности: `DEPLOY.md`; проверки: `docs/qa-2026-10-12/REPORT.md`.
