# Осколок для iPhone

Нативная оболочка (Swift, UIKit, WKWebView) вокруг https://oskolok.lol/app. Интерфейс и функции приходят с сайта,
оболочка добавляет фоновое воспроизведение, экран блокировки, обработку прерываний аудио, офлайн-экран и проверку
новой версии. Исходники ведутся в основном репозитории (`ios/`); этот репозиторий нужен только для сборки на macOS-раннере.

Сборка: `brew install xcodegen && xcodegen generate`, затем Xcode или workflow `.github/workflows/ios.yml`
(неподписанный IPA + запуск UI-теста в симуляторе). Подпись выполняет Sideloadly/AltStore Apple ID пользователя
или Xcode с командой разработчика. Подробнее: `docs/ios.md` основного репозитория.
