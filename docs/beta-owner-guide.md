# Как управлять бета-тестированием

Всё делается в боте @oskolokplayerbot с твоего аккаунта (ID 1784522503 записан на сервере как админ).

**Новая заявка.** Когда человек отправил форму на oskolok.lol/beta и нажал «Подтвердить в Telegram», бот пришлёт карточку «💎 OSKOLOK — НОВАЯ ЗАЯВКА». В ней username, цель, «о себе», платформы, номер и дата.

**Принять.** Нажми «✅ Принять». Заявка станет одобренной, доступ привяжется к Telegram-аккаунту человека, бот поздравит его и даст кнопку «Перейти к Осколку». Карточка изменится на «✅ ЗАЯВКА ОДОБРЕНА», кнопки решения исчезнут.

**Отклонить.** Нажми «❌ Отклонить». Человек получит вежливое сообщение. После этого можно нажать «📝 Причина отказа» и написать причину — человек увидит её только на странице статуса. «💬 Комментарий» — заметка для себя, её никто не видит.

**Передумал или нажал дважды.** Повторное нажатие ничего не ломает: бот ответит «Уже решено». Изменить решение из бота нельзя; напиши разработчику.

**Закрыть набор.** `/close_beta` или «🔒 Закрыть набор» в `/admin`. Форма на сайте сменится сообщением «Набор временно закрыт» со ссылкой на канал, сервер перестанет принимать заявки. Отправленные заявки останутся, их можно рассматривать.

**Открыть набор.** `/open_beta` или «🔓 Открыть набор».

**Статистика.** `/admin` — всего, ожидают, принято, отклонено, состояние набора. `/stats` — подробно: за сутки, процент одобрения, платформы. `/beta_status` — коротко.

**Найти заявку.** `/applications` — список ожидающих (кнопками можно переключить одобренные, отклонённые и неподтверждённые, листать страницы). `/applications ios` — только iOS. `/find username` — поиск. `/app 125` — заявка №125.

**Выгрузить заявки.** `/export` пришлёт CSV-файл. В нём личные данные: не пересылай его.

**Опубликовать новую сборку.**
1. Windows/macOS/Android: собрать (`DEPLOY.md`, раздел «Приложения»), положить файл с тем же именем в `/var/www/oskolok-downloads`, затем `releases.js add` с новой версией. Страница загрузок покажет новую версию и дату сама.
2. iPhone: запушить изменения в `pexepo/oskolok-ios`, скачать IPA из артефакта GitHub Actions, положить в `/var/lib/oskolok/releases` и выполнить `releases.js add --platform ios … --private --beta-only`. Скачать его смогут только бета-тестеры.

Команды `releases.js` — в `docs/site-and-beta.md`. Если сомневаешься, попроси Claude: «опубликуй сборку X».

**Обновить приложение для iPhone.** Изменения сайта приходят сами. Новая сборка оболочки нужна редко; после публикации у тестеров в приложении появится окно «Новая версия» с кнопкой на гайд.
