# Проверка Осколка — 11 октября 2026

Сайт развёрнут: https://oskolok.lol/. Основные сценарии проверены, полный публичный выпуск приложений требует проверки на устройствах.

## Исправлено

- Запрошенное упрощение настроек профиля и читаемость имени, статуса, кнопки редактирования и полей. Старые значения сохранены.
- DELETE без тела: удаление лайков и плейлистов; проверка Origin остаётся обязательной для чужого Origin.
- Сохранение аватара и баннера одновременно: разрешены два изображения по 849 КБ, лимит JSON для профиля 3 МБ; остальные API 2 МБ.
- Неподдерживаемые ссылки импорта: понятное сообщение HTTP 400 вместо общего HTTP 500.
- Публичный профиль открывается без входа; скрытые витрина и тексты не выдаются через полный профиль, карточку или пагинацию.
- Критическая инъекция shell в резервном yt-dlp: запрос передаётся отдельным аргументом execFile, а не исполняется оболочкой.
- Production-зависимости обновлены, npm audit --omit=dev: 0 известных уязвимостей на момент проверки. Electron обновлён до 44.7.0.
- Новые установщики содержат только клиент сайта. Внутри app.asar проверены 9 записей; .env, базы и сервер отсутствуют. APK также без секретов.
- Docker/compose согласованы с SQLite и устанавливают Python-зависимости; конфигурация подготовлена, контейнер не запускался.

## Оставшиеся ограничения

Реальный вход Telegram до завершения, экспорт музыки в Telegram, OAuth музыкальных площадок и TIDAL требуют проверки с владельцем аккаунтов. Установка и воспроизведение на Windows/Android не подтверждены; устройств нет. Desktop не подписан сертификатом издателя, DMG не нотарифицирован. APK использует WebView: фон/экран блокировки не имеют нативной аудиослужбы. Автотесты не заменяют эти проверки. Нагрузочный предел VPS не измерен.

В инструментах разработки остаются npm-advisories; devDependencies не установлены в активном production-выпуске. Контейнерная конфигурация не проверена запуском Docker. Резервные копии на VPS не спасают от потери всего VPS; отдельный снимок скопирован на компьютер владельца, внешнее автоматическое хранение не настроено.

Старые EXE из release вне distribution не распространять: в них есть .env и SQLite. Они сохранены, новые артефакты находятся в distribution.
