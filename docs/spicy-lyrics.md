# Spicy Lyrics в Осколке

Осколок получает синхронизированные тексты через официальный [Spicy Lyrics API](https://developers.spicylyrics.org/docs). Запрос выполняется сервером; секретный ключ не попадает в браузер или Telegram Mini App.

1. Создайте приложение в [Developer Dashboard](https://developers.spicylyrics.org/dashboard) и скопируйте секретный ключ `sl_sk_…` при создании.
2. В серверном `.env` задайте `SPICY_LYRICS_SECRET_KEY=sl_sk_…` и перезапустите сервер. Не используйте префикс `VITE_` и не сохраняйте ключ в Git.
3. Для SQLite выполните `npm run db:push`. Для PostgreSQL примените `npm run db:push:pg` к нужной базе, затем запустите сервер.
4. Откройте в Осколке трек из каталога Spotify. Текст должен показать фактический источник: Spicy Lyrics, Apple Music или Spotify. Для пользовательской разметки появятся ссылки на загрузившего и создавшего синхронизацию.

API принимает **Spotify ID трека**, а не ссылку SoundCloud или YouTube. Для треков других площадок Осколок сначала ищет точное совпадение названия, исполнителя и длительности среди уже известных ему Spotify-релизов. Если настроены `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET`, он также ищет в каталоге Spotify; ремиксы и другие версии автоматически не подменяются. Spotify Premium для получения текста через Spicy Lyrics не нужен. Если ID не найден, ключ отсутствует или сервис не ответил, остаётся прежний поиск текстов через настроенный `LYRICS_PROVIDER_URL` и LRCLIB. Воспроизведение звука через Spotify этот ключ не включает.

Страница автора Spicy Lyrics в Осколке — внешняя карточка, а не локальный аккаунт. Ссылка ведёт на его настоящую страницу, а счётчик показывает только треки, разметки которых уже были получены и показаны в Осколке. Кэш ответов Spicy Lyrics хранится не дольше 30 дней; по истечении срока запись обновляется или больше не показывается. Доступ к маршруту текстов требует авторизации в Осколке, как и остальные внутренние API.

Источники: [метод Get Lyrics](https://developers.spicylyrics.org/docs/reference/get.lyrics), [авторство](https://developers.spicylyrics.org/docs/attribution), [ключи](https://developers.spicylyrics.org/docs/keys), [условия и срок кэша](https://developers.spicylyrics.org/terms).
