# Интерференция

Самостоятельный режим текста, вдохновлённый пословным выделением Spicy Lyrics. Код Spicy Lyrics не копировался.

## Как использовать

1. Включите трек и нажмите «Интерференция» в нижнем плеере (или клавишу L вне поля ввода).
2. Текст загружается автоматически из настроенного каталога и LRCLIB. Если источники ничего не нашли, плеер разбирает страницу соответствующей песни на Genius и показывает текст без синхронизации. Если доступны только времена строк, вся строка проявляется как один сегмент; плеер не выдумывает времена отдельных слов.
3. Кнопка загрузки принимает LRC, Enhanced LRC с `<mm:ss.xx>` перед словами, TTML с временными метками `begin` / `end` и JSON. Максимальный размер — 1 МБ.
4. Точный импорт использует сегменты из файла: строки, слова или слоги. Это означает использование меток файла, а не проверку их соответствия вокалу.
5. «Разметить слова»: вставьте текст, начните воспроизведение, нажимайте кнопку в начале каждого слова. Последним нажатием отметьте окончание. Можно отменить последнюю отметку.
6. Смещение от −10 до +10 секунд сохраняется для трека. Положительное значение показывает текст раньше. Клик по строке перематывает к ней с учётом смещения.
7. Прокрутка вручную приостанавливает слежение за текущей строкой; плавающая кнопка «К текущей строке» возвращает его. Настройки текста открываются значком в верхней панели. Строки выровнены по центру.
8. Скачайте JSON для обмена. Импорт сохраняется в IndexedDB этого браузера/устройства. Он не публикуется и не синхронизируется между пользователями или между браузером и Electron.
9. «Вернуть текст из каталога» удаляет локальную версию для данного трека.
10. Выделенный фрагмент строки тоже перематывает к её началу. Аннотация Genius открывается только по иконке рядом с фрагментом и небольшой области вокруг неё; повторный клик по той же иконке закрывает панель. Панель плавает поверх правого края и не сдвигает текст: раскладка строк при открытии и закрытии не меняется, анимируются только `transform` и `opacity`. Выбранный фрагмент подсвечивается во всех своих строках.
11. Фрагменты Genius ищутся во всём тексте песни, а не построчно: фрагмент может начинаться и заканчиваться посреди строки и пересекать строки, как бы они ни были разбиты. Допускаются пропущенное слово, опечатка (`ayy`/`aye`) и имя в другой письменности (`Томми`/`Tommy`); реплики в скобках, которых нет в основных строках, не мешают. Сервер читает со страницы Genius порядок фрагментов в песне: по нему выбирается нужное повторение припева и привязываются фрагменты из одного слова. Без порядка одиночные слова привязываются только если они редкие. Пересекающиеся фрагменты делят одну иконку, метки секций вроде `[Verse 1]` не отображаются.
12. Если отрисовка строки с аннотацией даёт сбой, строка показывается простым текстом; сбой всего текста песни показывает небольшую карточку «Повторить» и не затрагивает остальной плеер. Направление строки определяется по первой букве, а не по знакам препинания: тире, `’` и `…` не делают строку «справа налево».

## Формат JSON

`public/examples/interference-demo.json` — самостоятельный учебный текст, не разметка конкретной песни. `public/examples/interference-demo.ttml` — тот же пример в TTML.

```json
{"version":1,"lines":[{"time":1,"end":5,"text":"Звук становится светом","words":[{"text":"Звук","start":1,"end":2},{"text":"становится","start":2,"end":3.5},{"text":"светом","start":3.5,"end":5}]}]}
```

Все времена — секунды от начала аудио. Слова идут по возрастанию начала; конец не раньше начала. TTML поддерживает абсолютные `hh:mm:ss.mmm`, `mm:ss.mmm`, смещения `h` / `m` / `s` / `ms`, кадровые и тиковые метки, Apple-агентов, фоновые дорожки, переводы и романизацию. Относительные времена вложенных контейнеров пока не поддерживаются.

## Караоке-подсветка — 22 сентября

Режим выбирается по точности файла. Несинхронизированный текст остаётся статичным. Строчные метки дают один вертикальный градиент на всю фактическую высоту фразы, поэтому переход остаётся непрерывным после переноса. Слова и слоги с собственными интервалами получают горизонтальную заливку; направление для RTL-текста обращается. Старые сегменты с `estimated: true` считаются строчными и не дробятся на вымышленные слова.

Прогресс каждого интервала вычисляется только из позиции аудио: `p = clamp((time + offset - start) / (end - start), 0, 1)`. Белая и серая части разделены мягкой зоной в 20%: её границы равны `1.2p - 0.2` и `1.2p`. Для протяжных сегментов до 12 графем применяется короткий последовательный акцент букв; графемы делятся через `Intl.Segmenter`, поэтому emoji и диакритика не распадаются.

Один планировщик обновляет CSS-переменные только у активных видимых строк. React меняет состояние на границах строк, а переносы выполняет браузер без покадровых измерений. Пауза, буферизация и скрытая вкладка останавливают цикл; перемотка и изменение смещения сразу пересчитывают заливку. Активная фраза остаётся чёткой, соседние мягко размываются, а ручная прокрутка и наведение снимают размытие. В режиме уменьшения движения остаётся синхронная цветовая заливка, но отключаются подъём букв, масштабирование, размытие и плавная автопрокрутка.

## Фон Fluted Glass

Фон «Интерференции» использует WebGL1-шейдер Fluted Glass. Четыре цвета извлекаются из обложки текущего релиза и сортируются от тёмного к светлому; при недоступной обложке используется встроенная резервная палитра. Canvas ограничивает плотность пикселей значением 2, не реагирует на курсор или аудиоспектр и приостанавливает цикл в скрытой вкладке. При системном уменьшении движения остаётся один статичный кадр.

Шейдер адаптирован из [Paper Shaders — Fluted Glass](https://shaders.paper.design/fluted-glass) и распространяется по лицензии [Apache-2.0](https://github.com/paper-design/shaders).

Кнопка «В Telegram-профиль» находится под источником трека. Подробности и ограничения — в `docs/telegram-feasibility.md`.
