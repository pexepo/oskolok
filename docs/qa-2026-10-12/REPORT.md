## Исправления

- Мобильный полноэкранный плеер: старый CSS превращал первый блок кнопок в огромный квадрат. Использованы явные классы, естественная высота и размер обложки с учётом доступного экрана. На компьютере высота колонок ограничена; кнопка Telegram больше не обрезается.
- Коллекция: компактные заголовки, карточки, навигация и нижний плеер. Учтены безопасные области Telegram и стабильная высота WebApp; цвета нативных панелей соответствуют теме.
- Обложки: ограниченный прокси известных CDN через свой домен, дисковый кэш, повторные попытки. Исправлена нулевая высота вложенного изображения релиза в Safari. Начатые загрузки не отменяются при прокрутке.
- Telegram-профиль: подготовка аудио использует одну общую загрузку вместо конкурирующих записей в один временный файл. Сохранение атомарное, с проверкой формата, размера, полноты HTTP-ответа и тайм-аутом. Ошибки не скрываются за минутным опросом кэша. Запросы к Telegram и клиент ограничены по времени; повторный клик во время отправки блокируется. Отсутствие MTProto-сессии больше не разлогинивает сайт.
- Резервный каталог: сбой поиска треков не уничтожает успешный результат поиска артиста. Отрицательное сопоставление Spotify/Deezer перепроверяется через пять минут; проверенные сопоставления сохраняются.
- Обновления: `version.json`, проверка открытого клиента раз в три минуты и при возвращении. Уведомление и кнопка обновления; автоматическое применение в спокойном состоянии. Музыка, редактирование и открытые диалоги защищены от автоматической перезагрузки.
- Публикация: `npm run deploy` проверяет сборку и тесты локально и на Linux с отдельной базой, делает backup и переключает отдельный выпуск с откатом при неудачном запуске. Старые ленивые JS-компоненты сохраняются. Настройки и пользовательские данные не входят в архив.

## Практические ограничения

- Для получения первого обновления старый открытый клиент нужно один раз полностью закрыть и открыть.
- EXE/DMG/APK из `release/distribution` используют общий сайт и получают изменения сайта без переустановки. Автообновления самих нативных исполняемых файлов нет; для изменений оболочки нужна новая сборка и установка.
- Spotify Web API временно ограничивает запросы. Резервный каталог доступен, но наличие анимации по словам зависит от таймингов конкретной песни и возможности определить её Spotify ID. Системная настройка уменьшения движения учитывается.
- Добавление в настоящий Telegram-профиль подтверждено владельцем после исправления кэша. Агент при проверках не выполнял SaveMusic на аккаунте владельца.
- Физические iPhone/Android/Windows здесь не тестировались. Получены два из пяти обещанных скриншотов; остальные экраны можно проверить после их получения.
