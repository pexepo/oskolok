# Персона артиста: релизы без пропусков, чужих и повторов

## Проблема

Deezer — каталог-первоисточник, но профиль Deezer ≠ человек:

- **Пропуски.** Один артист разбросан по нескольким профилям с одинаковым именем (Дима clout: часть релизов на 206095887, часть на 11597).
- **Несовпадения.** В один профиль положены однофамильцы (11597: группа 1978 года, латиноамериканский исполнитель и Дима).
- **Повторы.** Тот же релиз в нескольких профилях / сервисах.

Прежняя логика смотрела на один профиль и вычитала чужое, а правило «тонкий профиль уступает популярному» уводило страницу Димы на профиль группы 70-х.

## Алгоритм (`server/src/services/releaseIdentity.ts`)

1. **Пул.** Релизы открытого профиля + до 4 профилей Deezer с тем же именем (сравнение без регистра, диакритики и пунктуации).
2. **Кластеры.** Union-find по фактам релиза: лейбл как написан, соавторы, общие названия треков. Не связывают: агрегаторы, лейбл = имя артиста, соавтор с тем же именем (любой однофамилец самиздатом пишет «Clout»).
3. **Якорь (кто эта страница).** По порядку:
   - `seedAlbum` — релиз, с которого слушатель открыл артиста (`/artist/:id?from=<deezer album>`);
   - доверенная дискография (Spotify-карточка);
   - хиты открытого профиля.
4. **Сходство с якорем.** Письменность, страна ISRC, романские названия, стиль регистра, жанр, эпоха (медиана года, разрыв > 12 лет — −3).
   - Кластер с открытого профиля (без семени) остаётся, если сходство > −2.
   - Кластер с другого профиля (или любой при семени) входит только при сходстве ≥ 2.
   - Хиты выбирают только якорь: хиты однофамильца на том же профиле его не оправдывают. Общее название с доверенной дискографией — доказательство.
5. **Остальные персоны** — блок «Другие исполнители с этим именем» на странице, ссылка открывает их по их релизу.
6. **Повторы** — прежний `dedupeReleases` после пула.

Решение кэшируется (`dz-persona:v4:<profile>:<refs>:<seed>`, 12 ч; неполное — 5 мин), факты релизов — 30 дней.

## Проверка

- `tests/releaseIdentity.test.ts`: случай clout с трёх входов.
- Живые данные: clout (оба профиля и семя) — 12 релизов Димы с любого входа; pyrokinesis, Rizza, Скриптонит, Oxxxymiron, Земфира, Radiohead, Кишлак, Slava Marlow, Boulevard Depo, ЛСП — без потерь.

## Не входит

Склейка одноимённых артистов в поиске: каждый профиль Deezer остаётся отдельной карточкой; разбор происходит на странице артиста.
