# Осколок — проверка 13 октября 2026

Опубликован выпуск `20261013152456`, build ID `2026-10-13T15:25:02.338Z`. Служба активна, API health: `ok`; после переключения в журнале нет EROFS/error/unhandled/failed. Общий кэш подключён к `/var/lib/oskolok/data` и прошёл проверку записи и атомарного переименования под ограничениями службы.

## Изменения

- ПКМ: устранён условный вызов React-хука в меню (#310). Меню и информация о треке создаются только при открытии.
- Текст: пробел на выбранной строке управляет воспроизведением; Enter сохраняет переход к строке.
- Навигация: центр на компьютере; «Друзья» внутри панели. На телефоне — отдельная круглая кнопка 62 × 62.
- Плеер: нативная полоса прокрутки скрыта, прокрутка сохранена. Размер обложки учитывает место для кнопок.
- Большие списки: виртуализация «Любимых», плейлистов и очереди; полная коллекция остаётся доступна для поиска, воспроизведения и перестановки. Строки подписаны только на свои изменения, а не на всё состояние библиотеки.
- Очередь: общий CSS делал фиксированную панель частью потока и растягивал её на весь список. Панель получила явную позицию и ограниченную высоту.
- Нагрузка: меньше обновлений прогресса и системной MediaSession; фон плеера рисуется с меньшим разрешением и частотой. Nginx сжимает большие JSON-ответы.
- Telegram: восстановлено подключение общего кэша, добавлена проверка записи под ограничениями службы перед публикацией. Предыдущая музыка сохраняется во время подготовки/загрузки следующей. Полные короткие файлы меньше 500 КБ больше не отклоняются только из-за размера.
- Библиотека: точное сравнение названий вместо поискового приближения, которое склеивало повторяющиеся буквы/цифры. Чтение «Любимых» больше не удаляет записи из базы. Исправление предотвращает дальнейшее удаление; ранее удалённые записи автоматически не восстанавливались.
- База: одновременная и повторная инициализация схемы стала безопаснее; на Linux проверено сохранение существующей библиотеки и доступа.
- Звук: плавная шкала и более тихий максимум, анализ LUFS полного кэшированного файла, плавная коррекция громких записей и запас для эквалайзера. Анализ выполняется последовательно и кэшируется, воспроизведение не ждёт его. Тихие записи не усиливаются. Цель до регулятора громкости −14 LUFS соответствует ориентиру [Spotify](https://support.spotify.com/us/artists/article/loudness-normalization/); алгоритм не полностью повторяет Spotify.
- Обложки: прокси отдаёт изображение с именем `oskolok-artwork.jpg` вместо адреса без расширения.
- Бот: кабинет доступен без беты; профиль, сайт, скачивание Windows/macOS/Android, информация, TikTok, Telegram, донат и заявка. Вход в плеер по-прежнему требует приглашения. Старт и главное меню не рекомендуют Mini App. Используются баннер и премиум-эмодзи; при отказе Telegram — обычные иконки. Права на custom emoji определяются [Telegram Bot API](https://core.telegram.org/bots/api#formatting-options).
- Оболочки 1.1.1: F12 явно открывает/закрывает DevTools; Android содержит службу воспроизведения, MediaSession, системное уведомление и кнопки, мост стал публичным для WebView. Подпись совпадает с предыдущим APK.

## Ограничения

- Проценты CPU и память на физическом Windows-компьютере, а также уведомление/фон на реальном Android здесь не измерены. Нужен повторный тест друга на новых сборках.
- Нормализация Web Audio работает в поддерживаемых браузерах и Android/desktop. На iOS сохранён прямой системный звук для фонового воспроизведения; эта обработка там недоступна. Spotify и внешний плеер Telegram обрабатывают звук сами.
- Треки без доступного полного аудиофайла, отозванная сессия и лимиты Telegram не могут быть устранены обещанием «100%». Ошибки показываются, операции ограничены по времени и используют существующий механизм повторов.
- Перетаскивание изображения в настоящий чат Telegram отдельно не выполнялось; проверены JPEG, тип и имя файла.
- После изменения оболочки нужно установить 1.1.1. Изменения сайта приходят автоматически.
