# Кнопки Моей волны

Осколок уже использует React, TypeScript, Tailwind CSS и алиас `@/* → src/*`. Компонент находится в принятой здесь директории [`src/components/ui/shiny-button.tsx`](../src/components/ui/shiny-button.tsx), а стили — в `src/index.css`. Папка `src/components/ui` сохраняет единое место для переиспользуемых элементов; в этом проекте исходный код расположен под `src`, поэтому корневая `/components/ui` не используется.

Пример из задания рассчитан на `style jsx`, которого нет в Vite. Его анимация, блики и точки перенесены в обычный CSS без дополнительной зависимости. Изображения не требуются; иконки берутся из уже установленного `lucide-react`. Кнопки учитывают светлую и тёмную темы, клавиатурный фокус и `prefers-reduced-motion`.

Если в дальнейшем понадобятся компоненты из каталога shadcn, запустите `npx shadcn@latest init` в корне проекта, выберите Vite/TypeScript, Tailwind и путь CSS `src/index.css`, а алиас компонентов задайте как `@/components/ui`. Текущая кнопка работает без этой инициализации.
