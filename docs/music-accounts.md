# Музыкальные аккаунты Осколка

Откройте «Перенести музыку» → «Ваши аккаунты». Spotify и SoundCloud используют OAuth: Осколок не получает пароль. Яндекс Музыка подключается по коду устройства через [неофициальную библиотеку](https://github.com/MarshalX/yandex-music-api); этот способ зависит от изменений Яндекса. Токены сохраняются в зашифрованной базе пользователя на сервере.

## Spotify: настройка приложения

1. Создайте приложение в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard). Добавьте точный Redirect URI `http://127.0.0.1:5000/api/music-accounts/spotify/callback` для локального сервера с `PORT=5000`. Для публикации добавьте `https://ваш-домен/api/music-accounts/spotify/callback`.
2. Укажите `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` в серверном `.env`. Секрет не должен иметь префикс `VITE_`.
3. Укажите `MUSIC_OAUTH_ORIGIN=http://127.0.0.1:5000` или публичный HTTPS origin, совпадающий с callback. Перезапустите сервер.
   Каталог Spotify в поиске, подсказках и релизах начинает работать сразу после настройки двух серверных ключей. Пользователю не нужен Premium для просмотра каталога; Premium требуется для воспроизведения через Spotify. Без ключей Осколок явно показывает резервный каталог Deezer. Прямая ссылка Spotify на трек или альбом по-прежнему открывается отдельно.
   Проверьте обычный поиск: над результатами должно появиться «Каталог Spotify», а у треков — источник Spotify. Если показан Deezer, проверьте значения обоих ключей и журнал ответа Spotify. Ключ Spicy Lyrics не заменяет ключи Spotify: он отвечает только за тексты.
4. В Осколке нажмите «Spotify · Войти», подтвердите доступ к библиотеке и управлению воспроизведением. Если аккаунт был подключён до появления плеера Spotify, отключите его и войдите заново.
5. Для импорта нажмите «Плейлисты». Для звука нужен Premium. В браузере Осколок использует Web Playback SDK; в Electron выберите открытое устройство Spotify Connect в том же блоке. На странице релиза или рядом с треком выберите Spotify в меню «Источник». «Автовыбор» предпочитает Spotify, когда подключённый аккаунт содержит точную версию трека.

Для теста с друзьями вход в Spotify не обязателен: бот и каталог Осколка доступны каждому вошедшему через Telegram. Если друг хочет подключить **свой** Spotify-аккаунт, в Spotify Developer Dashboard откройте приложение → Settings → Users Management → Add new user и внесите имя и email его Spotify-аккаунта. Development Mode допускает не более пяти авторизованных Spotify-пользователей; владелец приложения должен иметь Premium. Не создавайте новые Client ID как обход этого ограничения. [Правила Development Mode](https://developer.spotify.com/documentation/web-api/concepts/quota-modes).

Spotify не предоставляет Осколку аудиофайл. Для Telegram Осколок ищет доступный полный файл той же версии из другого источника; если такого файла нет, синхронизация этого трека не состоится. SDK требует совместимого браузера и защищённого воспроизведения, а [политика Spotify](https://developer.spotify.com/policy) ограничивает публичные приложения, объединяющие потоки разных сервисов. Ключ приложения сам по себе не даёт разрешения на публичный коммерческий запуск.

## SoundCloud

1. Зарегистрируйте приложение согласно [инструкции SoundCloud](https://developers.soundcloud.com/docs/api/register-app). Для выдачи ключей сервис может требовать Artist Pro.
2. Зарегистрируйте Redirect URI `http://127.0.0.1:5000/api/music-accounts/soundcloud/callback` либо соответствующий HTTPS адрес.
3. Задайте `SOUNDCLOUD_CLIENT_ID`, `SOUNDCLOUD_CLIENT_SECRET`, `MUSIC_OAUTH_ORIGIN` и перезапустите сервер.
4. В «Ваших аккаунтах» нажмите «SoundCloud · Войти», затем выберите плейлист. Токен обновляется сервером; одноразовый refresh token заменяется после каждого обновления.

## Яндекс Музыка

1. Установите Python зависимость на сервере: `python -m pip install -r server/python-requirements.txt` из исходников или `python -m pip install -r dist-server/services/python-requirements.txt` из сборки. Если Python находится не в стандартном месте, задайте `PYTHON_PATH`.
2. Откройте «Яндекс Музыка · Войти» в Осколке. Перейдите по показанной ссылке Яндекса и введите код. Осколок автоматически проверит подтверждение.
3. Нажмите «Плейлисты», выберите «Любимые треки» или подборку. Записи сопоставляются с каталогом Осколка по названию и исполнителю; не найденные записи отмечаются в предпросмотре.

Подключение Яндекса использует неофициальный Device Flow библиотеки `yandex-music==3.0.0`. Оно даёт доступ к библиотеке для импорта; прямое воспроизведение Яндекс Музыки не подключено.

## Проверка и ошибки

- «Подключение ещё не настроено»: проверьте переменные и перезапуск процесса.
- `Redirect mismatch`: сравните протокол, домен, порт и путь callback посимвольно.
- Spotify `403` в каталоге: проверьте разрешения приложения, список пользователей и режим доступа API; Premium пользователя к поиску не относится. В режиме разработки владелец приложения должен соответствовать текущим требованиям Spotify. Spotify `403` в плеере: проверьте Premium и разрешения воспроизведения. После изменения разрешений подключите аккаунт заново.
- Spotify SDK не запускается: выберите доступное устройство Connect. В Electron звук играет на выбранном устройстве.
- Яндекс не открывает список: проверьте установку Python зависимости и повторите вход по коду.
- `429`: площадка ограничила запросы. Повторяйте после указанного ею интервала.

Для Telegram Mini App используйте один публичный HTTPS origin и оба HTTPS callback. Локальный `127.0.0.1` на телефоне указывает на сам телефон. Секреты храните только на сервере.
